# 🛠️ DevToolkit 产品说明文档

> 版本：1.0.0 | 更新日期：2026-05-15

---

## 简介

**DevToolkit** 是一款跨平台桌面应用，专为程序员打造。将日常开发中频繁使用的编码转换、数据格式化、加解密、文本对比等 16 类工具整合到一个统一的界面中，无需浏览器、无需联网，数据不出本机。

### 一句话描述

> 开发者的瑞士军刀 —— 29 个常用工具，一个应用全搞定。

---

## 下载安装

| 平台 | 格式 | 最低系统要求 |
|------|------|-------------|
| macOS | `.dmg` | macOS 10.15+ (支持 Intel & Apple Silicon) |
| Windows | `.msi` / `.exe` | Windows 10+ |
| Linux | `.deb` / `.AppImage` | Ubuntu 20.04+ |

### 安装方式

- **macOS**: 双击 `.dmg` → 拖入 Applications 文件夹
- **Windows**: 双击 `.msi` 或 `.exe` 安装程序 → 按提示完成
- **Linux**: `sudo dpkg -i dev-toolkit_x.x.x_amd64.deb` 或直接运行 `.AppImage`

## 功能一览

### 🕐 时间戳转换

在 Unix 时间戳与人类可读日期之间互转。

| 功能 | 说明 |
|------|------|
| 当前时间戳 | 实时显示当前 Unix 时间戳（秒/毫秒） |
| 时间戳→日期 | 输入时间戳，输出格式化日期（支持秒/毫秒自动检测） |
| 日期→时间戳 | 输入日期字符串，输出对应时间戳 |

**示例**：
```
输入: 1715760000
输出: 2024-05-15 08:00:00 (Asia/Shanghai)
```

---

### 📝 JSON 工具

JSON 格式化、压缩、校验、去转义，一站式处理。

| 功能 | 说明 |
|------|------|
| 格式化 | 美化 JSON，2 空格缩进 |
| 压缩 | 去除空白，单行输出 |
| 校验 | 检查 JSON 语法，定位错误位置 |
| 去转义 | 还原转义序列（`\"` → `"`，`\n` → 换行，`\uXXXX` → Unicode 等） |

**代码折叠**：格式化后支持按级别折叠（1/2/3 级、全部折叠/展开），快速浏览大型 JSON 结构。

**去转义示例**：
```
输入: "{\"name\":\"hello\\nworld\"}"
输出: {
  "name": "hello
world"
}
```

---

### 📄 文本对比

逐行逐词对比两段文本，清晰标识差异。

| 功能 | 说明 |
|------|------|
| 逐行对比 | 基于最长公共子序列 (LCS) 算法，精确识别增删改 |
| 逐词高亮 | 修改行中，差异的词用颜色标注 |
| 同步滚动 | 左右面板联动滚动 |
| 统计信息 | 显示相同/修改/删除/新增行数 |

**颜色编码**：
- 🟢 绿色 → 新增内容
- 🔴 红色 → 删除内容
- 🟡 黄色 → 修改内容（词级差异用绿/红标注）

---

### 🔍 正则测试

实时测试正则表达式，查看匹配结果。

| 功能 | 说明 |
|------|------|
| 正则匹配 | 输入正则表达式和测试文本，高亮所有匹配 |
| 分组捕获 | 显示每个匹配的分组内容 |
| 标志位 | 支持全局(g)、忽略大小写(i)、多行(m)等标志 |

---

### 📊 文本统计

快速统计文本的字数、行数、字符数。

| 指标 | 说明 |
|------|------|
| 字符数 | 含/不含空白字符 |
| 单词数 | 按空白分隔 |
| 行数 | 总行数、非空行数 |
| 字节数 | UTF-8 编码大小 |

### 🔐 Base64 编解码

文本与 Base64 互转。

```
编码: Hello World → SGVsbG8gV29ybGQ=
解码: SGVsbG8gV29ybGQ= → Hello World
```

---

### 🌐 URL 编解码

URL 百分号编码与解码。

```
编码: 你好世界 → %E4%BD%A0%E5%A5%BD%E4%B%B8%96%E7%95%8C
解码: %E4%BD%A0%E5%A5%BD → 你好
```

---

### 🔣 Unicode 编解码

文本与 Unicode 转义序列互转。

```
编码: Hello → \u0048\u0065\u006c\u006c\u006f
解码: \u0048\u0065\u006c\u006c\u006f → Hello
```

---

### 📎 HTML 实体编解码

HTML 特殊字符与实体互转。

```
编码: <div class="test"> → &lt;div class=&quot;test&quot;&gt;
解码: &amp;copy; → ©
```

---

### 🔒 哈希计算

计算文本的 MD5 / SHA-1 / SHA-256 / SHA-512 哈希值。

| 算法 | 输出长度 | 用途 |
|------|---------|------|
| MD5 | 32 hex | 文件校验（非安全场景） |
| SHA-1 | 40 hex | Git 提交哈希 |
| SHA-256 | 64 hex | 通用安全哈希 |
| SHA-512 | 128 hex | 高安全场景 |

---

### 🔑 HMAC-SHA256

使用密钥生成 HMAC-SHA256 签名。

```
输入消息: hello world
输入密钥: my-secret-key
输出: 7b3a6e5c8d2f...
```

典型用途：API 请求签名、Webhook 验证。

---

### 🛡️ AES 加解密

AES-256-GCM 对称加解密，认证加密防篡改。

| 参数 | 说明 |
|------|------|
| 算法 | AES-256-GCM |
| 密钥派生 | PBKDF2 |
| Nonce | 随机 12 字节 |
| 输出格式 | Base64 编码 |

**使用场景**：加密敏感数据、安全传输配置信息。

---

### 🔢 进制转换

在 2~36 进制之间自由转换。

```
输入: FF (十六进制)
输出: 255 (十进制) | 11111111 (二进制) | 377 (八进制)
```

---

### 🎨 颜色转换

HEX / RGB / HSL 颜色值互转，带颜色预览。

```
输入: #6c5ce7
输出: RGB(108, 92, 231) | HSL(251°, 75%, 63%)
```

---

### 🎫 JWT 解码

解析 JWT Token，展示 Header、Payload、Signature。

```
输入: eyJhbGciOiJIUzI1NiIs...
输出:
  Header:  { "alg": "HS256", "typ": "JWT" }
  Payload: { "sub": "1234567890", "name": "John", "iat": 1516239022 }
```

> 注意：仅解码，不验证签名。

---

### 🔗 URL 解析

解析 URL 的各个组成部分。

```
输入: https://example.com:8080/path?q=hello#section
输出:
  协议: https
  主机: example.com
  端口: 8080
  路径: /path
  查询: q=hello
  锚点: section
```

## 通用功能

### 🔍 持久搜索栏

任何编辑器中按 `⌘F` (macOS) 或 `Ctrl+F` (Windows/Linux) 打开搜索栏。

| 功能 | 快捷键/操作 |
|------|------------|
| 打开搜索 | ⌘F / Ctrl+F |
| 下一个匹配 | Enter / ▼ |
| 上一个匹配 | Shift+Enter / ▲ |
| 大小写敏感 | 点击 Aa |
| 正则搜索 | 点击 .* |
| 关闭搜索 | 点击 ✕ 或 Esc |

> 搜索栏常驻显示，不会在找到后消失。

### 📐 编辑器调整大小

拖动编辑器底部的 `⠿` 手柄，垂直调整编辑器高度。

### 📂 侧边栏折叠

- 点击 `◀` 收起侧边栏，获得更大工作区
- 点击 `☰` 展开侧边栏

### 🗂️ JSON 代码折叠

在 JSON 输出编辑器中：
- 点击行号旁的 `▸` 折叠/展开代码块
- 使用工具栏的折叠级别按钮快速折叠到指定层级

## 常见问题

### Q: 数据会上传到服务器吗？
**A**: 不会。所有数据处理完全在本地完成，没有任何网络请求。

### Q: 支持哪些加密算法？
**A**: 哈希（MD5/SHA-1/256/512）、HMAC-SHA256、AES-256-GCM 对称加解密。

### Q: 文本对比支持多大的文件？
**A**: 理论上无限制，CodeMirror 虚拟渲染支持大文本。LCS diff 算法在行数超过 5000 时会自动降级为简单对比以保证性能。

### Q: AES 加密的密钥有什么要求？
**A**: 任意字符串均可。应用内部会通过 PBKDF2 将你的密码派生为 256-bit 加密密钥。

### Q: 如何构建 Windows 版本？
**A**: 需要在 Windows 机器上构建，或使用 GitHub Actions CI 自动构建。详见项目 README。
